# Tor FSM-MDT: REPLAY Saldırısı — Non-Circular Sinyal Analizi

## Sorun: Önceki Koşunun Circular Olması

Önceki koşuda `[FSM-REPLAY]` log satırı hem saldırı kodu tarafından yazılıyor hem de parser tarafından okunuyordu. Bu bir **tautoloji**'dir: env kapalıyken o satır hiç yazılmadığı için attack=31, benign=0 sonucu tanım gereği çıkıyordu. Gerçek bir tespit değildi.

---

## Adım 0 — Organik Sinyal Arayışı

```bash
grep -rniE "replay|duplicate|seen before|already|reject.*cell" \
  src/core/or/ src/feature/relay/ src/core/crypto/
```

**Sonuç:** `relay.c` veya `command.c` içinde organik "replay cell rejected" log satırı bulunamadı. Talimat gereği GHOST yoluna geçildi; ancak asıl organik sinyal **Chutney multi-node ortamında** tespit edildi.

---

## Organik Sinyal: `n_chan already set. Bug/attack. Closing.`

**Kaynak:** `src/feature/relay/circuitbuild_relay.c`, satır 68:

```c
static int
circuit_extend_state_valid_helper(const struct circuit_t *circ)
{
  /* ... */
  if (circ->n_chan) {
    log_fn(LOG_PROTOCOL_WARN, LD_PROTOCOL,
           "n_chan already set. Bug/attack. Closing.");
    return -1;
  }
  /* ... */
}
```

**Mekanizma:** Client bir RELAY_COMMAND_EXTEND2 (komut=14) hücresi gönderdiğinde, yama bu hücreyi `circuit_package_relay_cell()` üzerinden **bir kez daha** enjekte eder. Guard relay, ilk EXTEND2'yi işleyip devreyi `n_chan` ile genişletir. İkinci (duplicate) EXTEND2 geldiğinde `circ->n_chan` zaten set edilmiş olduğundan bu log satırını üretir.

**Non-circular kanıtı:** Bu satır `circuitbuild_relay.c`'de, saldırganın yamasından (`relay.c`) bağımsız olarak üretilir. Relay, saldırganın marker'ını okumaz; kendi FSM durumunu kontrol eder.

## Neden Non-Circular?

| Özellik | Circular (eski) | Non-Circular (yeni) |
|---------|-----------------|---------------------|
| Sinyali kim üretiyor? | Saldırganın kendi kodu (`relay.c`) | Guard relay'in kendi FSM kontrolü (`circuitbuild_relay.c`) |
| Env kapalıyken çıkar mı? | Hayır (tanım gereği 0) | Hayır (duplicate hücre gönderilmediği için) |
| Env açıkken çıkar mı? | Evet (marker yazıldığı için) | Evet (relay duplicate EXTEND2'yi reddediyor) |
| Bağımsız mı? | Hayır | **Evet** — relay saldırganın log'unu okumaz |
| Gerçek tespit mi? | Hayır (tautoloji) | **Evet** |
